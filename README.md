# Retail Customer Retention Analytics

## 📌 Project Overview

This project focuses on analyzing customer behavior and retention patterns for a retail business using data analytics and Power BI.

The objective is to identify customer segments, understand purchasing behavior, analyze retention-related metrics, and create an interactive dashboard that can support data-driven business decisions.

## 🎯 Business Objective

The main objectives of this project are:

* Analyze customer purchasing behavior
* Identify customer retention patterns
* Understand customer segmentation
* Analyze sales and customer-related KPIs
* Identify trends and patterns in customer activity
* Create an interactive Power BI dashboard
* Generate actionable business insights

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Microsoft Excel / CSV** – Dataset handling
* **Data Analytics** – Customer segmentation and retention analysis

## 🔄 Project Workflow

The project followed these major steps:

1. Data Collection
2. Data Understanding
3. Data Cleaning
4. Data Transformation
5. Data Modeling
6. DAX Measure Creation
7. Exploratory Analysis
8. Dashboard Development
9. Customer Retention Analysis
10. Business Insights

## 📊 Dashboard

The Power BI dashboard provides an interactive view of customer and retention-related metrics.

### Key Dashboard Areas

* Customer Overview
* Customer Segmentation
* Retention Analysis
* Sales Analysis
* Customer Behavior
* KPI Monitoring
* Interactive Filters and Slicers

## 💡 Key Insights

The analysis helps identify:

* Customer retention and churn patterns
* Differences in customer behavior across segments
* High-value and low-value customer groups
* Customer purchasing trends
* Areas that may require customer retention strategies

> Detailed findings and supporting analysis are available in the project documentation.
